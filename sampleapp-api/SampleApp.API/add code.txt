
Да, сейчас ID сортируется как текст, а не как число.
Поэтому получается:

12, 13, 14, 2, 3...

вместо:

2, 3, 4, 5...

Что исправить

Полностью замени файл:

src/hooks/useSort.ts

на этот код:

import { useMemo, useState } from 'react';

export type SortDirection = 'asc' | 'desc';

export type SortConfig<T> = {
  key: keyof T | null;
  direction: SortDirection;
};

export const useSort = <T extends Record<string, unknown>>(
  data: T[],
  initialConfig?: SortConfig<T>
) => {
  const [sortConfig, setSortConfig] = useState<SortConfig<T>>(
    initialConfig || { key: null, direction: 'asc' }
  );

  const sortedData = useMemo(() => {
    if (!sortConfig.key) return data;

    return [...data].sort((a, b) => {
      const aRaw = a[sortConfig.key];
      const bRaw = b[sortConfig.key];

      const aNumber = Number(aRaw);
      const bNumber = Number(bRaw);

      const bothAreNumbers =
        aRaw !== null &&
        aRaw !== undefined &&
        bRaw !== null &&
        bRaw !== undefined &&
        !Number.isNaN(aNumber) &&
        !Number.isNaN(bNumber);

      if (bothAreNumbers) {
        return sortConfig.direction === 'asc'
          ? aNumber - bNumber
          : bNumber - aNumber;
      }

      const aValue = String(aRaw ?? '').toLowerCase();
      const bValue = String(bRaw ?? '').toLowerCase();

      return sortConfig.direction === 'asc'
        ? aValue.localeCompare(bValue)
        : bValue.localeCompare(aValue);
    });
  }, [data, sortConfig]);

  const requestSort = (key: keyof T) => {
    let direction: SortDirection = 'asc';

    if (sortConfig.key === key && sortConfig.direction === 'asc') {
      direction = 'desc';
    }

    setSortConfig({ key, direction });
  };

  return {
    sortedData,
    sortConfig,
    requestSort,
  };
};

Почему это исправит

Теперь хук сначала пытается понять, можно ли оба значения превратить в числа.
Если да — сортирует как числа.
Если нет — сортирует как строки.

То есть:
	•	id будет сортироваться правильно
	•	login и name останутся строковой сортировкой

После этого ID будет идти нормально:
	•	по возрастанию: 2, 3, 4, 5, 12, 13, 14
	•	по убыванию: 14, 13, 12, 5, 4, 3, 2

Если хочешь, я сразу дам ещё фикс, чтобы в таблице поиск по ID тоже работал стабильно, даже если id приходит строкой.
