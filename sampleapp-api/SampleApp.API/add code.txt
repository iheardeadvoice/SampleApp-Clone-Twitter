Да. Ниже даю готовый интерфейс для API по твоему swagger.json — чтобы можно было сразу использовать во фронте.

Сделаем 2 файла:
	1.	src/types/swagger.ts — все типы и DTO
	2.	src/api/swaggerApi.ts — все методы API

2) Файл

src/api/swaggerApi.ts

import { apiClient } from './client';
import type {
  EditMicropostDto,
  LoginDto,
  Micropost,
  MicropostDto,
  Role,
  User,
  UserDto,
  UserUpdateDto,
} from '../types/swagger';

/* =========================
   MICROPOSTS
========================= */

export const getMicroposts = async (): Promise<Micropost[]> => {
  const response = await apiClient.get<Micropost[]>('/Microposts');
  return response.data;
};

export const getMicropostById = async (id: number): Promise<Micropost> => {
  const response = await apiClient.get<Micropost>(`/Microposts/${id}`);
  return response.data;
};

export const createMicropost = async (
  payload: MicropostDto
): Promise<Micropost> => {
  const response = await apiClient.post<Micropost>('/Microposts', payload);
  return response.data;
};

export const updateMicropost = async (
  id: number,
  payload: EditMicropostDto
): Promise<Micropost> => {
  const response = await apiClient.put<Micropost>(`/Microposts/${id}`, payload);
  return response.data;
};

export const deleteMicropost = async (id: number): Promise<Micropost> => {
  const response = await apiClient.delete<Micropost>(`/Microposts/${id}`);
  return response.data;
};

/* =========================
   ROLES
   В swagger ответы у Roles описаны как массив User.
   Оставляю строго по swagger.
========================= */

export const getRoles = async (): Promise<User[]> => {
  const response = await apiClient.get<User[]>('/Roles');
  return response.data;
};

export const getRoleById = async (id: number): Promise<User[]> => {
  const response = await apiClient.get<User[]>(`/Roles/${id}`);
  return response.data;
};

export const createRole = async (payload: Role): Promise<User[]> => {
  const response = await apiClient.post<User[]>('/Roles', payload);
  return response.data;
};

export const updateRole = async (payload: Role): Promise<User[]> => {
  const response = await apiClient.put<User[]>('/Roles', payload);
  return response.data;
};

export const deleteRole = async (id: number): Promise<void> => {
  await apiClient.delete(`/Roles/${id}`);
};

/* =========================
   SEED
========================= */

export const generateSeed = async (): Promise<void> => {
  await apiClient.get('/Seed/generate');
};

/* =========================
   TOKEN
========================= */

export const getTokenInfo = async (): Promise<unknown> => {
  const response = await apiClient.get('/Token');
  return response.data;
};

/* =========================
   USERS
========================= */

export const loginUser = async (payload: LoginDto): Promise<UserDto> => {
  const response = await apiClient.post<UserDto>('/Users/Login', payload);
  return response.data;
};

export const createUser = async (payload: LoginDto): Promise<UserDto> => {
  const response = await apiClient.post<UserDto>('/Users', payload);
  return response.data;
};

export const getUsers = async (): Promise<UserDto[]> => {
  const response = await apiClient.get<UserDto[]>('/Users');
  return response.data;
};

export const getUserById = async (id: number): Promise<UserDto> => {
  const response = await apiClient.get<UserDto>(`/Users/${id}`);
  return response.data;
};

export const updateUser = async (
  id: number,
  payload: UserUpdateDto
): Promise<UserDto> => {
  const response = await apiClient.put<UserDto>(`/Users/${id}`, payload);
  return response.data;
};

Как использовать

Пример логина:

import { loginUser } from '../api/swaggerApi';

const user = await loginUser({
  login: 'admin',
  password: '123',
});

Пример пользователей:

import { getUsers, getUserById, updateUser } from '../api/swaggerApi';

const users = await getUsers();
const user = await getUserById(5);

await updateUser(5, {
  name: 'Иван',
  login: 'ivan90',
});

Пример micropost:

import { createMicropost, getMicroposts } from '../api/swaggerApi';

await createMicropost({
  content: 'Привет!',
  userId: 5,
});

const posts = await getMicroposts();


⸻

Важно

У тебя в swagger есть странность:
эндпоинты /api/Roles и /api/Roles/{id} в ответах описаны как массив User, а не Role. Я оставил строго по swagger, чтобы интерфейс совпадал с твоим JSON.

Если хочешь, следующим сообщением я могу сделать тебе ещё готовую страницу Swagger UI внутри React: вкладки Users / Microposts / Roles с формами и кнопками для всех этих методов.
